# Single Owner, admin area without authentication

The service books the calendar of exactly one Owner, and the admin area is open to anyone who has the link: there is
no login and no notion of several Owners. The course scenarios describe one calendar and no sign-in, and this keeps the
learning project focused on Event Types, Slots and Bookings. Adding authentication or several Owners later means
scoping every Event Type and Booking to an Owner and protecting the admin endpoints, so do not "fix" the open admin
area piecemeal.
