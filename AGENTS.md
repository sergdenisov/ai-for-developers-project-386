# Agent rules

These rules apply to every coding agent. `CLAUDE.md` only imports this file.

## Project overview

Call booking service: `backend/` (Fastify, TypeScript) and `frontend/` (React, Vite, Mantine) are separate npm
packages; the root `package.json` holds repository-wide tooling only.

## Checks

- Run `mise run check` before you call a change done. It must pass: CI runs the same command.
- Run `mise run fix` for safe autofixes (formatting, Markdown, lint fixes).
- Tool versions are pinned in `mise.toml`; git hooks are defined in `hk.pkl`.
- Do not bypass hooks with `--no-verify`.

## Dev servers

- Start the backend and frontend dev servers with `mise run dev`; they run as mise daemons (pitchfork).
- Use `mise daemons status`, `mise daemons logs <name>`, `mise daemons restart <name>` and `mise daemons stop`
  instead of starting servers in your own shell. Daemons: `backend`, `frontend`.

## Rules and exceptions

- Never disable a lint rule or weaken a check to get a change through.
- An exception is narrow (one path and one rule), carries a reason in the config, and needs a human decision.
  Exceptions that hide a security finding also get a review date.

## Files you do not edit by hand

- `.github/workflows/hexlet-check.yml` and `.github/workflows/README.md` are generated by Hexlet; the course forbids
  editing them.
- `package-lock.json` files change only through npm.

## Commits

Write commit messages in [Conventional Commits](https://www.conventionalcommits.org/) format; commitlint checks them
in the `commit-msg` hook and in CI.
